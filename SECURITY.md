# Security policy

## Reporting a vulnerability

**Please don't open a public GitHub issue for security reports.** This repo
ships the rrxiv reference server as well as the SDK, so vulnerabilities should
reach the maintainer privately, before disclosure:

- **Email**: <albisburdige@protonmail.com>
- **Subject line**: `[security] rrxiv-python — <short description>`

Include a description of the vulnerability and its impact, steps to reproduce,
and the rrxiv-python and Python versions you're on. You'll get an
acknowledgement within 72 hours and an initial triage within 7 days; disclosure
timeline is coordinated from there.

## Supported versions

rrxiv-python is pre-1.0. Security fixes land on `main` and ship in the next
release; older releases are patched only on a best-effort basis.
